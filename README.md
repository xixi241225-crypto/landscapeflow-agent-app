# LandscapeFlow AI｜景观方案设计总监智能体

LandscapeFlow AI 2.0 赛事演示完成版。

> 1 名景观方案设计总监智能体 + 6 个专业 Agent + 1 份可回写、可演进的项目设计蓝本 + N 个 Skills / 工具 + 4 个设计师确认节点

六个专业 Agent 依次为：项目定义、概念生成、方案选择、空间推演、视觉表达、成果输出。设计总监负责流程统筹，不是第七个专业 Agent。

- 对资深设计师，一人即团队。
- 对年轻设计师，随身设计导师。

## 本地运行

```bash
npm ci
npm run dev
```

默认访问 Vite 在终端输出的本地地址。生产构建：

```bash
npm run build
```

## 腾讯云黑客松现场路演模式

独立路演入口：

```text
http://localhost:5173/landscapeflow-agent-app/#/roadshow
```

路演模式使用固定脱敏社区项目、本地图片和预设确定性结果，不依赖网络接口。它由五个页面组成：项目载入、资料总览、项目设计蓝本、六 Agent 执行轨迹、完整成果中心；只保留一次关键设计方向确认。

快捷键：`→` / `Space` 下一步，`←` 上一步，`R` 重置，`1`–`5` 跳转五个页面。

详细交付说明见 `ROADSHOW_MODE_REPORT.md`。

## 赛事演示黄金路径

1. 首页点击“载入演示案例”。
2. 确认项目条件与资料状态，启动“路演演示模式”。
3. Agent 1 后确认项目事实，并接受或否定系统假设。
4. Agent 2–3 后选择 A / B / C，填写融合要求并保存决策。
5. Agent 4 后确认核心叙事、空间结构、分区、动线、专业策略和节点。
6. Agent 5–6 展示视觉成果集、报告和 12 页 PPT 预览，完成最终复核。

路演模式会自动衔接 Agent，但始终在四个设计师确认节点停下。点击“重新开始演示”可恢复到预置案例的初始状态。

## 核心数据流

```text
项目表单 / 项目资料
        ↓
项目设计蓝本当前版本 ← 设计师确认与上游修改
        ↓（Agent 运行前读取）
演示协作引擎
        ↓（只返回职责字段 Patch）
Blueprint 新版本 + 修改记录 + 下游失效传播
```

Blueprint 数据结构与服务位于 `src/blueprint/`；Agent 协作引擎位于 `src/providers/`；项目级本地持久化与导出位于 `src/lib/`。

## 当前演示边界

已完成 Blueprint 回写与版本历史、四个确认节点、上游修改与下游失效、项目级 localStorage、JSON / Markdown 导出、演示案例视觉成果以及动态 12 页 PPT 内容预览。

本轮不包含真实模型调用、PDF / Word / CAD 内容解析、定向图像生成、可编辑 PPTX 文件、云数据库、登录注册与云存储。

PPT 后续制作文案见 `docs/LandscapeFlow_AI_参赛路演PPT_占位文案.md`。
