# LandscapeFlow AI｜参赛路演 PPT 占位文案

> 用途：供 WorkBuddy 后续制作可编辑 PPTX。建议 16:9，延续绿色、金色、米白色的专业景观设计风格。

## 01｜封面

- 标题：LandscapeFlow AI｜景观方案设计总监智能体
- 副标题：对资深设计师，一人即团队；对年轻设计师，随身设计导师
- 建议视觉：满幅景观鸟瞰图，叠加 1+6+1 架构标签。

## 02｜行业痛点与设计任务

- 主要内容：景观方案需同时处理场地理解、概念创意、空间推演、专业策略、视觉表达和汇报组织，关键决策容易在多工具之间断裂。
- 建议视觉：传统碎片流程与统一蓝本流程对比。

## 03｜产品核心架构

- 主要内容：1 名景观方案设计总监智能体，统筹 6 个专业 Agent，围绕 1 份可回写、可演进的项目设计蓝本协作，并在 4 个节点由设计师确认。
- 建议视觉：中心总监、六 Agent 环形布局、下方 Blueprint 主档。

## 04｜六 Agent 工作流

- 主要内容：项目定义 → 概念生成 → 方案选择 → 空间推演 → 视觉表达 → 成果输出。
- 建议视觉：六步水平流程，突出当前 Agent 与蓝本版本进化。

## 05｜项目设计蓝本

- 主要内容：集中管理事实、来源、假设、约束、概念决策、空间与专业策略、视觉任务、PPT 结构、风险和修改历史。
- 建议视觉：蓝本抽屉截图，强调“已确认 / AI 建议 / 系统假设 / 待确认 / 已失效”。

## 06｜四个设计师确认节点

- 主要内容：项目事实确认、概念方向确认、项目设计蓝本确认、最终成果确认。Agent 可提供建议，但不替代设计师决策。
- 建议视觉：四个金色闸门交叉于六 Agent 流程。

## 07｜Demo：从项目理解到概念决策

- 主要内容：载入演示案例，Agent 1 区分事实与假设；Agent 2 生成 A/B/C 差异化方向；Agent 3 完成多维比选；设计师保存选择与融合要求。
- 建议视觉：三个概念卡片 + 比选表 + 决策面板。

## 08｜Demo：空间与专业策略深化

- 主要内容：Agent 4 严格读取设计师实际选择，生成核心叙事、空间结构、功能分区、动线、植物、材料、生态、竖向、排水和特色节点。
- 建议视觉：空间总平、策略卡片、第三确认节点截图。

## 09｜Demo：视觉任务与成果组织

- 主要内容：Agent 5 把当前蓝本拆分为鸟瞰、入口、核心场景、全龄活动、夜景、植物和总平等视觉任务，并组织演示案例视觉成果。
- 建议视觉：视觉任务卡片与图片网格。

## 10｜Demo：最终成果中心与 PPT 预览

- 主要内容：Agent 6 从当前 Blueprint 生成项目设计蓝本、方案设计报告、视觉成果集和 12 页汇报 PPT 结构。
- 建议视觉：最终成果中心 + 12 张 PPT 缩略页。

## 11｜上游修改与下游失效

- 主要内容：修改项目事实、概念决策或空间方案后，已有下游成果标记为“已失效，不属于当前方案”；旧成果保留用于对比，重新运行 Agent 后恢复为当前成果。
- 建议视觉：蓝本版本变化与 Agent 失效状态对比。

## 12｜产品价值与下一步

- 主要内容：LandscapeFlow AI 让景观方案工作从“多个孤立生成任务”转变为“设计总监统筹、多 Agent 协作、设计师决策、蓝本持续演进”。
- 下一步：接入真实模型、项目资料解析、定向图像生产与可编辑 PPTX 导出。
- 建议视觉：两句价值主张大字 + 下一步能力路线。
